# Schwebungen hören: Gleiche Cent, anderes Tempo

Persönliche Klaviernotizen von Juri Enes. Eine native marimo-Lernübung mit643Wörtern, zwei Werkstattaufnahmen, selbst erzeugtem Mono-Audio, einem Frequenzrechner und acht Fragen mit Erklärungen. Redaktion, Rechenmodell und Gestaltung mit KI-Unterstützung. Kein Bericht über einen bestimmten Schüler oder ein Kundeninstrument.

Lokal: `marimo run schwebungen.py`. Der öffentliche marimo-Reader wird nach der Prüfung hier verlinkt.

Die Fotografien werden vom bestehenden öffentlichen PIANOHOF-Bildbestand geladen. Das ergänzende Werkstattvideo zeigt Polyesterlack, keine Schwebungsdiagnose.
