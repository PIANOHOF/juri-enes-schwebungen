# Schwebungen hören: Gleiche Cent, anderes Tempo

Persönliche Klaviernotizen von Juri Enes. Eine native marimo-Lernübung mit 643 Wörtern, zwei Werkstattaufnahmen, selbst erzeugtem Mono-Audio, einem Frequenzrechner und acht Fragen mit Erklärungen. Redaktion, Rechenmodell und Gestaltung mit KI-Unterstützung. Kein Bericht über einen bestimmten Schüler oder ein Kundeninstrument.

Lokal: `marimo run schwebungen.py`. [Öffentliche Lernübung auf marimo](https://marimo.app/gh/PIANOHOF/juri-enes-schwebungen/main/e?embed=true&mode=read&show-chrome=false&entrypoint=schwebungen.py&src=https%3A%2F%2Fraw.githubusercontent.com%2FPIANOHOF%2Fjuri-enes-schwebungen%2Fmain%2Fschwebungen.py&include-code=false).
